### 2.4 `requirements.txt` / `requirements.lock` missing dashboard deps

`requirements.in` declares `fastapi>=0.110`, `uvicorn[standard]>=0.29`, `httpx>=0.27`.
Neither `requirements.txt` nor `requirements.lock` include these.

Impact: a fresh CI runner doing `pip install -r requirements.txt` would not install
the dashboard deps.  The dashboard tests skip gracefully when these are absent
(they're guarded with `pytest.importorskip`), so tests don't fail — but production
Docker builds from `requirements.txt` would lack the dashboard stack.

### 2.5 Architecture — `_collect_json` local re-implementation in `reporting.py`

`reporting.py` contains a local `_collect_json(root, names)` that calls `rglob`
to find any file by name, distinct from `_io.collect_json` which reads specific paths.
These do different things so the overlap is intentional — but the naming is confusing.
The local function should be renamed `_find_json_by_name` to distinguish it clearly.
(Low priority — deferred to next pass to avoid format churn.)
