- `report_html.cpython-312.pyc`
- `report_html.cpython-314.pyc`

Причина: `report_html.py` в `scripts/` запускался интерпретатором напрямую
в разных окружениях. `.gitignore` корректно покрывает `__pycache__/` и `*.pyc`,
в git не попало. Локально можно убрать:
```

```
