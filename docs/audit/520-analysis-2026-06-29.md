### 3.2 D8 WORKAROUND ПРИМЕНЁН (не отражено в 10-defects.md)

`scripts/update_trivy.sh` обновлён — вместо прямого `$FLAGS` в аргументах:

```sh
# Convert the rendered flag string into POSIX positional parameters...
# Reference: docs/audit/10-defects.md section 8.
# shellcheck disable=SC2086
set -- $FLAGS
```

Последующие вызовы используют `"$@"`, что устраняет основную проблему.
**Теоретически** word-splitting при `set -- $FLAGS` всё ещё уязвим к значениям
с пробелами, но на практике `TRIVY_RENDERED_FLAGS` содержит только простые флаги.
Это mitigation, не full fix — нужно задокументировать статус в `10-defects.md` (D8).
