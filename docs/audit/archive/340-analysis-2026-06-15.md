## 4. Критические дефекты (блокируют CI)

### D-RUFF-1 (P1) — ruff check: 1 ошибка SIM115

```
SIM115  Use a context manager for opening files
  tools/docker-mcp/server.py:554   log_fh = open(log_path, "w", encoding="utf-8")  # noqa: WPS515
```

**Причина:** файл открывается намеренно без `with` — `log_fh` должен жить за пределами
`with`-блока (передаётся в `subprocess.Popen`). Это корректный паттерн. Комментарий
`# noqa: WPS515` подавляет wemake-код, но **ruff проверяет свой собственный SIM115**,
который этим noqa не заглушается.

**Способ устранения:** заменить `# noqa: WPS515` на `# noqa: WPS515,SIM115`.

> Заодно `.ruff.toml` уже содержит `external = ["WPS515"]` (в uncommitted изменении),
> что предотвращает предупреждение об «неизвестном noqa-коде». Это изменение нужно закоммитить.

### D-RUFF-2 (P1) — ruff format: 6 файлов не форматированы

## 6. Новые наблюдения

### N5-1 (P2) — Нет теста для Windows-пути в `run_scan_async`

`tools/docker-mcp/server.py:514–576` содержит два крупных ветвления `if sys.platform == "win32"`:
один строит аргументы PowerShell, второй открывает `log_fh` и передаёт его в Popen.

`tests/test_docker_mcp_server.py` тестирует только валидацию входных данных (строки 123–125).
Ни один тест не мокирует `sys.platform == "win32"` и не проверяет:
- что args содержит `powershell.exe -File run-scan.ps1 -Target ... -Extract ...`
- что `log_fh` открывается при win32
- что Linux-ветка (bash) остаётся неизменной

**Риск:** изменения в этом коде не имеют регрессионного стражника.

**Способ устранения:** 2–3 теста с `monkeypatch.setattr(sys, "platform", "win32")` и
патчингом `subprocess.Popen`.

### N5-2 (INFO) — `.ruff.toml.new` — неотслеживаемый мусор

Файл `.ruff.toml.new` — копия текущего `.ruff.toml`. Никакой функции не несёт.
Кандидат на удаление без коммита.

### N5-3 (INFO) — CHANGELOG [Unreleased] отстаёт от HEAD на 5 коммитов

  stdout/stderr в `artifacts/run-scan.log`.

Функция `Import-RoutePlan` (`91c19cd`) содержит нетривиальную логику: проверка

(Pester) в проекте не настроен. Это не блокирует ничего, но усложняет рефакторинг.
