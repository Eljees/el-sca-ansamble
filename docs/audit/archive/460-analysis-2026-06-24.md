## 3. Выполненные правки

### A_OBS-1 — `_probe_layer` принимает `RetryPolicy` напрямую — ЗАКРЫТ

**Что было:** `_probe_layer` принимала 4 отдельных retry-параметра
(`retry_count`, `backoff_seconds`, `retry_status_codes`, `non_retryable_reasons`),
хотя все callers уже строили `RetryPolicy` через `from_tool_config`.

**Что сделано:**
- Сигнатура `_probe_layer` упрощена: один параметр `retry: RetryPolicy` вместо четырёх.
- Тело: `attempt_sources` вызывается через поля `retry.*` напрямую.
- `run_healthcheck` — trivy и grype передают `retry=<policy>`; cve-bin-tool строит
  `RetryPolicy` с переопределённым `retry_count` из `source_health_policy` (там нет
  секции `retry_backoff_policy`).
- `tests/test_healthcheck.py`: добавлен `from resilient_updates._retry import RetryPolicy`;
  3 call-sites `_probe_layer` обновлены.
- 4/4 тестов проходят.
