## 2. Defects found and findings

### 2.1 `RUF001` — ambiguous Cyrillic chars in dashboard.py HTML template [FIXED via config]

**File:** `resilient_updates/dashboard.py:407`

Line 407 is inside a triple-quoted HTML string.  The Russian text `НЕ` ("NOT") uses
uppercase Cyrillic Н (looks like Latin H) and Е (looks like Latin E).  Ruff's RUF001
rule flags both as potentially ambiguous.  Inline `# noqa: RUF001` inside a string
literal is not honoured by ruff for string-content rules.

**Fix:** added per-file-ignore to `.ruff.toml`:
```toml
"resilient_updates/dashboard.py" = [
  "RUF001", # HTML template intentionally uses Cyrillic uppercase (НЕ = NOT in Russian)
]
```

### 2.2 `F401` — unused `UploadFile` import in dashboard.py [AUTO-FIXED]

**File:** `resilient_updates/dashboard.py:570`

`UploadFile` was imported but never referenced.  Removed by `ruff check --fix`.

### 2.3 `SIM105` — bare `try/except/pass` in extractor.py [FIXED]

**File:** `resilient_updates/extractor.py:397–400`

```python
# Before
try:
    child.unlink()
except OSError:
    pass

# After
with contextlib.suppress(OSError):
    child.unlink()
```

Added `import contextlib` to the import block.

### 2.4 `UP035` — `Iterator` from `typing` instead of `collections.abc` [AUTO-FIXED]

**File:** `resilient_updates/orchestrator.py:32`

`from typing import Any, Iterator` → `from collections.abc import Iterator` (separate
import).  Fixed by `ruff check --fix`.

### 2.5 `UP037` — quoted type annotation [AUTO-FIXED]

**File:** `resilient_updates/orchestrator.py:233`

`def subscribe(self) -> "Queue[dict[str, Any] | None]":` → removed quotes.

### 2.6 `RUF100` × 2 — unused `# noqa: S603` directives in orchestrator.py [AUTO-FIXED]

**File:** `resilient_updates/orchestrator.py:328, 384`

`S603` (subprocess without shell) is not in the enabled ruleset (`.ruff.toml` selects

Removed by `ruff check --fix`.

### 2.7 `SIM105` — bare `try/except/pass` in orchestrator.py kill fallback [FIXED]

**File:** `resilient_updates/orchestrator.py:353–356`

```python

    proc.kill()
except Exception:
    pass

# After
with contextlib.suppress(Exception):
    proc.kill()
```

Added `import contextlib` to the import block (same import as §2.4).

### 2.8 `UP036` — version guard outdated for py312 target in test_vex.py [FIXED via config]

**File:** `tests/test_vex.py:20`

`if sys.version_info < (3, 11):` is flagged as an outdated version block because
`.ruff.toml` declares `target-version = "py312"`.  However, the guard IS needed: the
sandbox and local dev matrix include Python 3.10, where `from datetime import UTC`
raises `ImportError` at collection time.

**Fix:** added `UP036` to the `"tests/**"` per-file-ignores in `.ruff.toml` with an
explanatory comment.  No change to the test file itself.

### 2.9 bandit B108 × 2 — hardcoded `/tmp` in orchestrator.py [FIXED]

**File:** `resilient_updates/orchestrator.py:317–318`

```python
env.setdefault("SCAN_TARGET_HOST", "/tmp/el-sca-db-update-noscan")
env.setdefault("EXTRACT_INPUT_HOST", "/tmp/el-sca-db-update-noscan")
```

These placeholder values satisfy the `${SCAN_TARGET_HOST:?}` guard in `docker-compose.yml`
during update-only runs where no scan target exists.  The paths are never actually used
by the update services (documented in the comment above).  Suppressed with `# nosec B108`.

### 2.10 bandit B608 — orphaned nosec in cve_db_audit.py [NOT FIXED — known quirk]

Bandit emits `WARNING nosec encountered (B608), but no failed test on file ...cve_db_audit.py:80`.

itself did not fire on that file in this run.  The annotation was placed correctly in
