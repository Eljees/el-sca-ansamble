## 1. Fixes applied this pass

### 1.1 `Makefile` — remove `--maxfail=1` from `test` target (P4, **FIXED**)

`make test` previously stopped at the first failing test, hiding all
subsequent failures during local development. CI's explicit `pytest`
invocation does not use `--maxfail`, so developers using `make test`
got less information than CI.

**Change:** removed `--maxfail=1` from the `test` recipe. The full
failure list is now visible. Developers who want fast-fail locally can
pass `--maxfail=1` directly on the `pytest` command line.

### 1.2 `scanner_diff.py` — remove duplicate `_first_json` (SMELL, **FIXED**)

`resilient_updates/scanner_diff.py` contained a private `_first_json`
helper that was byte-for-byte identical to `_io.first_json` — the very
function introduced in `docs/audit/20-architecture.md §1` to eliminate
this duplication. The comment above the local copy even said
*"JSON loaders moved to resilient_updates._io"* but the local function
was never deleted.

**Change:**
- Replaced `from ._io import read_json as _read_json` with
  `from ._io import first_json as _first_json`
- Removed the 6-line local `def _first_json(...)` body
- Removed the now-unused `_read_json` alias (would have been a ruff F401)

All 5 `test_scanner_diff` tests pass after the change.

### 1.3 `.pre-commit-config.yaml` — ruff version drift (P2, **FIXED**)

The pre-commit hook pinned `ruff-precommit` at `v0.5.7`, while:
- The local developer has ruff `0.15.15` installed (confirmed from `.ruff_cache/`)
- CI uses `pip install "ruff>=0.5"` (resolves to `0.15.x` or newer)

This ~10-version gap means pre-commit and CI enforce different lint
rules. New rules in `0.6` through `0.15` (e.g. additional `FURB`,
`RUF`, `SIM` checks) apply in CI but are silently skipped by
pre-commit. The risk is that a commit passing pre-commit could fail CI
on the first lint-python job.

**Change:** bumped `rev: v0.5.7` → `rev: v0.15.15` to match local and
CI ruff exactly.

> **Note:** after running `pre-commit install` the first `git commit`
> will trigger a one-time download of the new ruff binary (~5 MB).
> Run `pre-commit autoupdate` periodically to keep hooks current.
