## 5. Архитектурные наблюдения (без правок)

### A3 — `cli.py` — три логические зоны в одном файле

`cli.py` (1214 строк) содержит:
1. CLI-парсер (argparse + `main()`)
2. Update-workflow (`update_grype`, `update_trivy`, `_update_cve_bin_tool`, …)
3. Health-check logic (`_health_summary`, `_probe_layer`, …)

Это не дефект, но при необходимости добавления новых команд логика станет заметно сложнее.
ADR-0005 Phase 3 (B6) предусматривает `scan.py` как thin wrapper — часть CLI может мигрировать туда.

### A4 — `dashboard.py` — нет unit-тестов для WebSocket endpoint

`test_dashboard.py` (797 строк) помечен `integration` (выполняется при `fastapi` в окружении).
WebSocket live-поток (`/ws/monitor`) не охвачен тестами — если dashboard тест падает в
sandbox из-за отсутствия fastapi, этот путь остаётся без регрессионной защиты на CI.  
**Приоритет:** низкий (UI-функция, не критический путь).
