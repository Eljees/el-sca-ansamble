### D3 — Таймер активного этапа в GUI (`ae47c7f`)

**Новая возможность:** В дашборде каждый активный этап показывает
тикающий таймер (`▶ 1m 23s`) в реальном времени, обновляемый каждую секунду
через `setInterval`. Пульсирующая анимация рамки для визуального акцента.

**Реализация:**
- CSS: `.stage.active { animation: pulse-border 1.8s ease-in-out infinite; }`
- JS: `stageStartMs{}` сохраняет метку входа в active; `setInterval` каждые
  1000ms обновляет `.timer` div в соответствующем элементе этапа.

### D4 — Heartbeat 10s по умолчанию, near-source артефакты (`ae47c7f`)

**Heartbeat:** `EL_SCA_HEARTBEAT_SECONDS` по умолчанию изменён с 30 на 10.
GUI и CLI не выглядят «зависшими» во время долгих этапов.

**Near-source артефакты:** `EL_SCA_RUN_OUTPUT_MODE` по умолчанию `"auto"`.
В режиме `auto` директория со всеми артефактами скана создаётся рядом с
исходным файлом как `<package>-<YYYYMMDD-HHMMSS>/`, а не в
`artifacts/runs/<id>/`. Это позволяет находить результаты рядом с целью.

Реализация в `run_layout.py` уже существовала; в orchestrator только изменили
дефолт.

### D6 — Фикс WSL getcwd в collect-report (`56963cd`)

**Проблема:** `Path("artifacts").resolve()` в `collect-report` падал с
`FileNotFoundError: [Errno 2] No such file or directory` из-за того, что
`os.getcwd()` не работает на DrvFS-путях WSL при передаче относительного пути.

**Фикс в `scripts/run-scan.sh`:**
```bash
# было:
"$PYTHON_BIN" -m resilient_updates.cli collect-report --reports-dir artifacts ...
# стало:
"$PYTHON_BIN" -m resilient_updates.cli collect-report --reports-dir "$ARTIFACTS_DIR" ...
```

То же для `report_html.py --artifacts-dir`. `ARTIFACTS_DIR` — абсолютный путь,
задаётся как `$(pwd)/artifacts` в начале скрипта.
