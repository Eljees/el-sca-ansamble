### B3 (P3, carry-forward) — Windows atomic rename в cve_db_audit._activate

`shutil.move` не атомарен на NTFS для 6 ГБ файлов. `MoveFileExW` через ctypes.
Не блокирует Linux-продакшн. Открыт с аудита 240.

через dashboard.nvd.nist.gov. После ротации обновить `.env.local`, очистить `.env`.

## 5. Архитектурные наблюдения

### 5.1 orchestrator.py — 85% coverage, ~77 непокрытых строк

Основная масса — heartbeat thread + SSE-стриминг + реальные docker compose вызовы.
Всё это требует mock-subprocess или интеграционного тестирования. Технически можно
покрыть ещё 30–40 строк mock-based тестами для `_run_stream` логики, но это нетривиально.

**Рекомендация:** в следующем тест-спринте добавить 10–15 тестов через
`unittest.mock.patch("subprocess.Popen")` для heartbeat и streaming paths.

### 5.2 bundle/ — LFS-стаб файлы

На dev-машине git-lfs не смудживает bundle-файлы — они остаются как 134-байтовые
pointer files. `git status --short bundle/` показывает ` D bundle/...`. Это pre-existing
состояние, не поломка. При работе не задевать bundle/ при `git add`.

### 5.3 Версия 0.1.3 — что включено

Все фичи и фиксы, реализованные после v0.1.2 (2026-06-12): checkpoint+resume,
heartbeat, монитор, bootstrap, elapsed timer в GUI, near-source mode, фиксы
run-scan.sh/ps1, dashboard barrels, parity Linux/Windows entrypoints.
