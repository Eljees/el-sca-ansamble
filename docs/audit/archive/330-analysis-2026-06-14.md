## 0. Суть проекта (краткий ориентир)

**el-sca-ansamble** — контейнерный SCA-комплекс (Trivy, Grype, Syft, cve-bin-tool)

отчёты об уязвимостях (MD/HTML). Ключевые возможности: air-gap, Windows, Android APK,
fallback-цепочка источников, route-doctor, GUI-дашборд, proxy-chain, checkpoint+resume,
heartbeat, монитор, one-command bootstrap.

## 5. Архитектурные наблюдения (carry-forward)

### 5.1 `_NON_RETRYABLE_REASONS` vs `RetryPolicy` (N2, P3)

`resilient_updates/fallback.py:113` содержит независимый `frozenset`:
```python
_NON_RETRYABLE_REASONS = frozenset({
    FailureReason.INVALID_SCHEMA,
    FailureReason.AUTH_FAILURE,
    FailureReason.HTTP_4XX,
})
```
`RetryPolicy` в `_retry.py` не имеет поля `non_retryable_reasons`.
Изменение в `RetryPolicy` не влияет на логику в `fallback.py`.

**Способ устранения:**
1. Добавить `non_retryable_reasons: frozenset = field(default_factory=lambda: frozenset({...}))`
   в `RetryPolicy`, перечислив те же 3 причины.
2. Передавать `policy` (или `policy.non_retryable_reasons`) в `attempt_sources`.
3. Удалить `_NON_RETRYABLE_REASONS` из `fallback.py`.

Затронутые файлы: `_retry.py`, `fallback.py`, `test_fallback_core.py`, `test_retry_policy.py`.

### 5.2 orchestrator.py (1007 строк) — рост файла

После 10 новых тестов покрытие должно улучшиться с 85%, но истинный уровень
без CI-прогона неизвестен. Следующий приоритет: добавить 3–5 тестов для
`start_scan`-пути с несколькими `tools` и для `_apply_auto_route`-цепочки при
