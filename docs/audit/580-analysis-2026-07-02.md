## 6. Архитектурные наблюдения (новые)

### 6.1 CI матрица: py3.10 + py3.12

`ci.yml` запускает тесты на **двух** версиях Python (3.10 и 3.12). Важное следствие:
`try: from datetime import UTC except ImportError` в `provenance.py` НЕ требует
`# pragma: no cover` — except-блок реально исполняется в 3.10-ветке CI. Аудит 570
неверно рекомендовал добавить pragma. **Не добавлять.**

### 6.2 D8: update_trivy.sh — ограничения Alpine

Docker-compose `trivy-updater` и `trivy-scanner` запускают скрипт через `/bin/sh`
в Alpine-образе Aqua Security. Alpine sh = BusyBox, не Bash.
Корректный fix D8 (`mapfile` / `readarray`) потребует смены shebang на `#!/usr/bin/env bash`
и установки bash в контейнере (или multi-stage copy). Это нетривиально — риск > выгоды.
Текущий `set -- $FLAGS` + `"$@"` корректен для данных флагов (нет пробелов в значениях).
**Рекомендация**: оставить WORKAROUND, снизить приоритет до P5.
